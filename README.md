## 🚀 About Me

Hi there! 👋 I am **Manasa SB**, an **AI Engineer** passionate about designing and shipping intelligent, autonomous AI systems that solve real customer problems. 

Currently at **CRED**, I build multi-agent state machines, context engineering frameworks for Large Language Models (LLMs), real-time multilingual voice agents, and model context protocols (MCP). My focus is on turning cutting-edge AI capabilities into reliable, production-grade applications with zero hallucination, strict policy compliance, and high performance.

### 🧠 Generative AI & Agent Architecture
- **Multi-Agent Systems & State Machines**: Stateful node routing, orchestrators, and supervisor nodes built with **LangGraph** and **LangChain**.
- **Context Engineering**: System prompt layering, XML delimiter structuring, semantic token compression, and dynamic in-context learning.
- **RAG & Knowledge Base Injection**: Grounded RAG, cosine similarity retrieval, vector store management with **pgvector** and in-memory indexes.
- **Structured Function Calling**: Type-safe JSON schemas, parameter validation, and deterministic tool execution.

### 🎙️ Voice AI & Multilingual Speech NLP
- **Real-Time Voice Agents**: Turn-taking engines with STT → RAG → LLM → TTS pipelines, barge-in detection, and latency optimization.
- **Indic & Code-Mixed NLP**: Integration with **Saaras** (STT), **Bulbul** (TTS), and **Sarvam AI** models for Hindi, English, and regional code-mixing.
- **Human-in-the-loop (HITL)**: Confidence-based escalations, policy-guardrail routing, and PII redaction.

### 🔌 Developer Tooling & Protocols
- **Model Context Protocol (MCP)**: Custom MCP servers via **FastMCP** over `stdio` and `streamable-HTTP` transports.
- **Telemetry & Monitoring**: **OpenTelemetry (OTel)** metrics, latency budget guards, and INR cost tracking per API turn.
- **Query Parsers & Domain SDKs**: GAQL (Google Ads Query Language) in-memory parsing and multi-language SDK codegen (Python, Node, Java, PHP).

### ⚙️ Systems, Backend & Fullstack UI
- **Languages**: Python 3.11/3.12, TypeScript 5, SQL, JavaScript, HTML5/CSS3.
- **Backend & Data**: FastAPI, Pydantic v2, Asyncpg, PostgreSQL (pgvector), Redis, Kafka, Docker & Docker Compose.
- **Frontend & Analytics**: Next.js 14/16 (App Router), React 19, Vite, Tailwind CSS, Recharts analytics, HSL Glassmorphism UI.

- **Tech Stack**: Python 3.11, Sarvam AI, Setu MCP, RAG, pgvector, Redis, Kafka, Docker Compose.
